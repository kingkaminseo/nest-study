## Nest.js 란

Java Spring의 구조를 차용한 Node.js 환경의 새로운 프레임워크입니다.

프로그레시브 JavaScript를 사용하고, TypeScript로 개발되었으며 또한 OOP(객체 지향 프로그래밍), FP(함수형 프로그래밍), FRP(함수형 반응형 프로그래밍)의 요소를 결합했습니다.

-   Nest HTTP 서버 프레임워크

    -   Express (기본)
    -   Fastify (선택)

-   장점 : MVC 디자인 패턴을 기본 패턴으로 하므로 역할과 구현(또는 책임)이 명확하게 구분된다! (중요)

Express에 비해 Nest의 기본 구조가 세분화 되어있어

-   역할에 따른 기능이 명확
-   기능이 명확해짐에 따라 협업 시 효율적인 개발(역할 분담 등)이 가능
-   기능별로 세분화되어 있으므로 디버깅 및 유지 보수, 신규 기능 개발 시 효율적
